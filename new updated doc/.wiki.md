# Project Summary
The Hospital Management System (HMS) is a scalable, microservices-based platform designed to manage multiple hospitals efficiently. It provides a unified interface for hospital administration, patient management, clinical workflows, and billing processes. The system ensures strict data isolation for each hospital while offering a comprehensive dashboard for administrators to monitor and manage operations seamlessly. Key features include role-based access control, patient registration, appointment scheduling, and consolidated billing, making it a robust solution for healthcare providers.

# Project Module Description
- **Platform Service**: Manages hospital and user data, including feature flags and roles.
- **Auth Service**: Handles authentication and authorization for users.
- **Patient Service**: Manages patient registrations and medical records.
- **Clinical Service**: Oversees consultations, orders, and clinical workflows.
- **Billing Service**: Manages billing, payments, and invoice generation.
- **Pharmacy Service**: Handles inventory management and medicine dispensing.
- **Lab Service**: Manages lab tests and orders.
- **Radiology Service**: Manages radiology tests and orders.
- **Staff Service**: Manages staff scheduling and rosters.
- **Audit Service**: Logs all significant actions for compliance and tracking.
- **Notification Service**: Sends notifications via email and SMS.

# Technology Stack
- **Frontend**: Next.js 14+, TypeScript, Tailwind CSS, Shadcn-ui
- **Backend**: Node.js, NestJS, TypeScript
- **Database**: PostgreSQL (multi-tenant)
- **Cache**: Redis
- **Message Queue**: RabbitMQ
- **Storage**: S3/MinIO
- **Container**: Docker
- **Orchestration**: Kubernetes (optional)
- **API Gateway**: Nginx/Kong

# Usage
To set up the project:
1. **Install Dependencies**: Run `npm install` in the root directory for both frontend and backend.
2. **Build the Project**: Use `npm run build` to compile the application.
3. **Run the Application**: Execute `npm start` for the backend and `npm run dev` for the frontend.
